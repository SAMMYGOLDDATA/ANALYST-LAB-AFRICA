# Netflix Movies & TV Shows Analysis (SQL)

## Project Overview

This project analyzes the Netflix Movies and TV Shows dataset using Microsoft SQL Server. It was completed as part of the AnalystLab Africa Data Analytics Internship Program.

---

## Objectives

- Understand the dataset
- Clean and validate data
- Perform exploratory data analysis
- Generate business insights
- Visualize key findings

---

## Tools Used

- Microsoft SQL Server (SSMS)
- SQL
- Excel / Power BI
- GitHub

---

## Dataset

Netflix Movies and TV Shows Dataset from Kaggle.

---

## Data Cleaning

- Checked for missing values
- Removed duplicates
- Standardized formats
- Validated records
- Verified primary key

---

## Exploratory Analysis

- Movies vs TV Shows
- Top Countries
- Content Added by Year
- Ratings Distribution
- Most Common Genres

---

## Key Insights

- Movies dominate the Netflix library.
- The United States produces the most content.
- TV-MA is the most common rating.
- Netflix's catalog expanded rapidly over the years.
- Drama and International Movies are the leading genres.
