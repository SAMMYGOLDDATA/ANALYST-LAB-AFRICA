# Online Retail Data Cleaning & Exploratory Data Analysis (SQL)

## Project Overview

This project was completed as part of the **AnalystLab Africa Data Analytics Internship Program (Batch B)**.

The objective was to clean, validate, and analyze the Online Retail dataset using SQL to transform raw transactional data into an analysis-ready dataset and generate meaningful business insights.

---

## Project Objectives

* Understand the dataset structure
* Clean and validate the data
* Handle missing values and duplicates
* Standardize formats
* Perform exploratory data analysis (EDA)
* Generate business insights
* Prepare data for visualization and reporting

---

## Dataset Information

**Dataset:** Online Retail Dataset

**Rows:** 541,909

**Columns:** 8

### Features

* InvoiceNo
* StockCode
* Description
* Quantity
* InvoiceDate
* UnitPrice
* CustomerID
* Country

---

## Data Cleaning Tasks

The following cleaning operations were performed:

* Removed missing values
* Removed duplicate records
* Standardized text formatting
* Standardized date formats
* Removed invalid quantities
* Removed invalid prices
* Removed cancelled transactions
* Validated data consistency

---

## Exploratory Data Analysis

The analysis included:

* Summary statistics
* Top-selling products
* Highest revenue-generating countries
* Monthly sales trends
* Customer purchasing behaviour
* Revenue analysis
* Product performance

## Key Insights

* The United Kingdom generated the highest revenue.
* A small number of products accounted for a significant share of sales.
* Sales exhibited seasonal trends across the year.
* Loyal customers contributed disproportionately to total revenue.
* Data cleaning substantially improved the quality and reliability of the analysis.
